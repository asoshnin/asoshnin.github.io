# Протокол тестирования: MD-Speaker

**Дата тестирования:** 07.07.2026
**URL:** https://mdcopilot.online/mdspeaker
**Категория:** FOR ALL

## Описание сервиса

MD-Speaker — AI-инструмент медицинской диктовки ("AI scriber for medical notes creation by voice recording"), создающий структурированную клиническую документацию из голосовой записи.

Настройки перед записью:
- **Тип записи:** Simple medical record / Consultation with any patient using AI (ИИ добавит вероятные диагнозы и план обследования) / Dialogue between doctor and patient (аналогично, с диалогом) / Chemotherapist's appointment / Oncologist's appointment (анамнез, осмотр, план обследования) / Meeting protocol.
- **Модель распознавания речи:** MedPro (accurate) / MedLite (lite) / MedBro (reliable).
- Явное предупреждение: *"Please note: The patient must sign a consent form to allow the conversation to be recorded"* — важная и корректная с точки зрения комплаенса деталь, особенно для сценария "Dialogue between doctor and patient".

**Тарификация:** 1 кредит за минуту записи.

Раздел "My records" позволяет хранить, объединять ("Merge recordings") несколько записей — полезно для длинных консультаций, разбитых на части.

## Ограничение тестирования

**Важно:** этот сервис принципиально требует **живого аудиоввода через микрофон** — интерфейс не предоставляет способа загрузить готовый аудиофайл или текстовый пример для распознавания (в разделе "My records" на тестовом аккаунте не оказалось ни одной сохранённой записи, которую можно было бы изучить). Поскольку тестирование проводилось через браузерную автоматизацию без реального аудиоввода, **полноценно протестировать качество распознавания речи и последующей AI-структуризации в рамках этого протокола не удалось** — заявить о фактическом качестве расшифровки было бы недобросовестно без реальной записи голоса.

## Оценка на основании доступных наблюдений (частичная)

**Сильные стороны (по описанию/UI):**
- Специализация под медицинские сценарии (в т.ч. отдельно — приём химиотерапевта/онколога) значительно ценнее, чем универсальная диктовка: система, вероятно, ожидает и умеет распознавать профильную терминологию, сокращения, дозировки.
- Явный шаг с согласием пациента на запись разговора — редкая и важная деталь для клинического инструмента, снижающая юридические риски для врача.
- Выбор из 3 моделей распознавания (accurate/lite/reliable) даёт пользователю контроль над балансом "скорость/точность/цена".
- Функция объединения записей удобна для длинных или прерывающихся консультаций.
- Тарификация по минутам (а не по кредитам за "сообщение") интуитивно понятна для голосового инструмента.

**Риски и открытые вопросы (не проверено):**
- Неизвестно фактическое качество распознавания русской медицинской речи (акценты, скорость речи, шумы кабинета) — для приложения, ориентированного, по всей видимости, на русскоязычных врачей (судя по остальному интерфейсу и характеру тестовых вопросов на платформе), это критический параметр, который не проверить без реальной надиктовки.
- Неизвестно, как система обрабатывает диалоговый сценарий "doctor and patient" с точки зрения разделения реплик по говорящим (диаризация) — потенциально сложная задача, качество которой сильно влияет на полезность итогового протокола.
- Неясно, что происходит при плохом качестве записи/обрыве связи — есть ли автосохранение черновика.
- Нет очевидной возможности загрузить существующий аудиофайл (например, уже записанный диктофоном консультации) — если это действительно так, это ограничивает сценарии использования только "живой" записью через это же устройство/браузер.

## Итоговая оценка раздела: не оценено (функциональность требует голосового ввода)

Рекомендация для дальнейшего тестирования: провести отдельный ручной тест с реальной аудиозаписью на русском языке (тестовая консультация 2–3 минуты) для оценки точности распознавания и качества структурирования итогового протокола.
