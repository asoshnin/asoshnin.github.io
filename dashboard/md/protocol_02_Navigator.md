# Протокол тестирования: Navigator

**Дата тестирования:** 07.07.2026
**URL:** https://mdcopilot.online/navigator
**Категория:** FOR ALL

## Описание сервиса

Navigator — AI-ассистент для доказательных ответов на биомедицинские вопросы (по FAQ: "biomedical search assistant that retrieves evidence-based information from the internet with direct publication references").

Настройки перед запросом:
- **Search type:** Simple / Deep / Patient assistance
- **Where to search:** Everywhere / Academic search / Only in PubMed
- **Publication period:** All / Last year / Last 5 years
- Лимит запроса — 30 слов.

**Тарификация:** Simple — 1 кредит, Deep и Patient assistance — 2 кредита.

**Техническая заметка:** UI-элементы выбора режима реализованы как стандартный HTML `<select>` — клик мышью по опции в выпадающем списке не срабатывал (значение визуально не менялось), сработало только управление с клавиатуры (Down + Enter). Небольшой, но реальный UX-баг для части пользователей/автотестов.

## Тестовый запрос (Deep, Everywhere, All periods)

**Промпт (23/30 слов, на русском):**
> Какова эффективность и безопасность CAR-T терапии по сравнению с аутологичной трансплантацией при рецидивирующей крупноклеточной B-клеточной лимфоме второй линии, по данным последних рандомизированных исследований?

## Наблюдаемое поведение и содержание ответа

Ответ сгенерирован на английском языке (несмотря на русскоязычный вопрос) в виде развёрнутого систематического обзора из 7 разделов:

1. Резюме ключевых рандомизированных исследований 3 фазы (ZUMA-7, TRANSFORM, BELINDA) в табличном виде (продукт CAR-T, популяция, контрольная группа, первичная конечная точка).
2. Эффективность: OS/EFS/PFS с точными HR и 95% ДИ по каждому исследованию/мета-анализу (например, EFS HR 0.57, 95% CI 0.49–0.68).
3. Профиль токсичности (CRS/ICANS против миелосупрессии/инфекций при ASCT) с конкретными цифрами (CRS 3+ ст. ~6%, нейротоксичность ~21%).
4. Клиническая интерпретация — кому показан CAR-T, а кому ASCT.
5. Отдельный анализ ситуации, где ASCT может быть предпочтительнее (пациенты в полной/частичной ремиссии после second-line терапии) — с данными реестра CIBMTR.
6. Сравнение безопасности в этих подгруппах.
7. Практические рекомендации по выбору тактики + итоговое резюме.

В конце — блок "Perhaps you would like to ask" с тремя релевантными уточняющими вопросами для продолжения диалога, а также кнопки **References**, **Download PDF**, **Download Word**, **Additional question**, **Start again**.

## Проверка списка литературы

По кнопке "References" открылся список из 14 источников с кликабельными доменами — большинство ссылок ведут на первичные и авторитетные источники:
- pubmed.ncbi.nlm.nih.gov, pmc.ncbi.nlm.nih.gov (дважды)
- ashpublications.org (Blood/ASH, дважды)
- thelancet.com
- nature.com
- tandfonline.com
- ascopost.com, dailynews.ascopubs.org (ASCO)
- bmtinfonet.org (пациентский ресурс — единственный не строго академический источник)

Ключевые фактические утверждения (существование исследований ZUMA-7, TRANSFORM, BELINDA, их дизайн и итог по первичной конечной точке — ZUMA-7/TRANSFORM положительные, BELINDA отрицательное; данные CIBMTR по CR/PR) соответствуют реальной опубликованной литературе по гематологии/онкологии, что было перепроверено вручную по общедоступным знаниям на момент тестирования.

## Оценка качества ответа

**Сильные стороны:**
- Уровень детализации и структура ответа соответствуют качественному нарративному обзору литературы, который эксперт готовил бы вручную несколько часов — с конкретными HR, 95% ДИ, % событий, ссылками на конкретные РКИ.
- Разделение на "что показывают РКИ" и "что показывают реестровые/нерандомизированные данные" — методологически корректный и важный нюанс, который часто упускают более простые AI-инструменты.
- Прозрачный список литературы с рабочими доменами (в основном PubMed/PMC/Lancet/Nature/ASH/ASCO) — высокая проверяемость.
- Функция экспорта в PDF/Word полезна для дальнейшего использования в клинической работе или подготовке презентаций.
- Предложенные follow-up вопросы демонстрируют понимание клинического контекста запроса.

**Слабые стороны и риски:**
- Ответ на русскоязычный вопрос пришёл полностью на английском — для части целевой аудитории (русскоязычные врачи, для которых сделан весь остальной интерфейс и, судя по всему, продукт в целом) это неудобно и создаёт языковой барьер, особенно с учётом узкоспециализированной терминологии.
- Долгое время генерации (заметно дольше, чем в Mórbius) — уместно для "Deep" режима, но нет визуального таймера/прогресс-бара, кроме отсутствия финального текста при промежуточных проверках.
- Ссылка №14 (bmtinfonet.org) — пациентский информационный ресурс, а не первичный научный источник; смешение уровней доказательности в одном списке литературы без явной маркировки типа источника.
- Как и в Mórbius, нет встроенного запроса на уточнение вводных данных (например, возраст, коморбидность, доступность CAR-T центра), хотя вопрос был сформулирован достаточно общим образом, так что это ожидаемо.
- UX-баг с выбором режима через выпадающий список (см. выше) может привести к тому, что часть пользователей случайно отправит запрос в режиме Simple вместо Deep (или наоборот), думая, что выбрали нужный режим.

## Итоговая оценка раздела: 9 / 10

Один из сильнейших разделов платформы: по глубине и структуре ответ сопоставим с профессиональным нарративным обзором литературы, со списком проверяемых источников. Основной минус — англоязычный ответ на русский запрос и мелкий UX-баг выбора режима.
