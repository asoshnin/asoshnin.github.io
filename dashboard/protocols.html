Детальный анализ по протоколам

URL: mdcopilot.online/morbius · Категория: FOR ALL · Статус: Стабильный

Mórbius — продвинутый медицинский AI-агент, сочетающий генеративный ИИ с верифицированными медицинскими базами данных. Режимы: Basic chat, PRO mode, Web search. База знаний включает клинические рекомендации (NCCN, ESMO, ASCO, RUSSCO), материалы конференций ASH-2025/EHA-2026/ASCO-2026, медицинские калькуляторы, PubMed/PMC/OpenAlex/MedRxiv/BioRxiv/FDA.

Тестовый запрос: пациентка 62 лет с ХСНсФВ (ФВ 55%), ХБП 3б (СКФ 38), СД2 на инсулине, стабильной стенокардией — подбор схемы терапии согласно ESC/ACC.

✓ Сильные стороны

  • Автоматическая инициация цепочки инструментов: поиск по гайдлайнам, web-search (4+ раунда), PubMed
  • Структурированный ответ с резюме, патофизиологическим обоснованием, таблицами РКИ, ASCII-схемой терапии
  • Учёт коморбидности (ХБП, СД2, стенокардия) с данными HR, ДИ, %
  • Отдельный блок лекарственных взаимодействий и противопоказаний
  • План мониторинга по срокам — практически применим
  • Прозрачность: пользователь видит, какие источники запрашивались

⚠ Слабые стороны

  • Ссылки «AI analysis» без прямого DOI/PMID — сложно быстро проверить
  • Долгое время генерации (30–45 сек) даже в «базовом» режиме
  • Нет запроса уточнений (вес, АД, лабораторные показатели)
  • Нет явного дисклеймера о медицинском назначении
  • Счётчик кредитов не обновлялся в реальном времени

Итог: Один из самых сильных разделов платформы — сочетание генеративного ответа с видимым RAG-процессом даёт ощущение верифицируемости, а качество клинического содержания на уровне профильного справочника.

AI-ассистент для доказательных ответов на биомедицинские вопросы с прямыми ссылками на публикации. Режимы: Simple / Deep / Patient assistance. Поиск: Everywhere / Academic / PubMed. Период: All / Last year / Last 5 years. Лимит ввода — 30 слов.

Тестовый запрос (Deep): эффективность и безопасность CAR-T терапии vs аутологичной трансплантации при рецидивирующей крупноклеточной B-клеточной лимфоме второй линии.

✓ Сильные стороны

  • Уровень детализации сопоставим с профессиональным нарративным обзором — с конкретными HR, 95% ДИ, % событий
  • Разделение на РКИ и реестровые/нерандомизированные данные — методологически корректно
  • Прозрачный список из 14 источников (PubMed, Lancet, Nature, ASH/ASCO)
  • Функция экспорта в PDF/Word
  • Релевантные follow-up вопросы демонстрируют понимание контекста

⚠ Слабые стороны

  • Ответ на русскоязычный вопрос пришёл полностью на английском — языковой барьер
  • Нет визуального таймера/прогресс-бара при генерации
  • Ссылка №14 (bmtinfonet.org) — пациентский ресурс, а не первичный источник
  • UX-баг: выпадающий список режимов не работает мышью, только клавиатура

Итог: Один из сильнейших разделов платформы — по глубине и структуре ответ сопоставим с профессиональным обзором литературы со списком проверяемых источников.

URL: mdcopilot.online/oncolink · Категория: FOR ALL · Статус: Стабильный

Живая лента обновлений публикаций по гематологии/онкологии, организованная по 39 нозологическим/тематическим плиткам (Acute Leukemias, Breast Cancer, CAR T-cell therapy, Glioma, NSCLC и др., включая AI in Oncology). AI-обзор новых публикаций по кнопке.

Тестовый сценарий: раздел Non-Small Cell Lung Cancer → AI review of new publications над лентой из 10 свежих статей (датированных 2026-07-06 — буквально «вчера»).

✓ Сильные стороны

  • Публикации датированы «вчерашним» днём — ежедневно обновляемый фид с реальными DOI
  • AI-обзор синтезирует темы между статьями, а не суммирует каждую отдельно
  • Полная прослеживаемость до PMID по каждому утверждению
  • Широкий охват (39 категорий) с фокусом на онкогематологию
  • Низкая стоимость — 1 кредит, пригодно для ежедневного использования

⚠ Слабые стороны

  • Интерфейс и AI-обзор — исключительно на английском
  • Нет фильтра/сортировки по релевантности внутри темы
  • Нет отображения общего числа статей за период
  • Пересечение по смыслу с описанным в FAQ сервисом MedLink

Итог: Очень сильный и практически полезный инструмент для отслеживания литературы «в моменте» по узким онкогематологическим темам, с образцовой прослеживаемостью источников.

URL: mdcopilot.online/medicus · Категория: FOR ALL · Статус: Стабильный

AI-ассистент для поиска информации в клинических рекомендациях и руководствах. Источники: NCCN, ASCO, ESMO, NICE, ASA, AAP. Режим Deep Search. Предусмотрена загрузка собственных локальных протоколов через поддержку. Лимит ввода — 300 слов.

Тестовый запрос: показания, длительность и режим дозирования адъювантного осимертиниба при резецированном NSCLC IB-IIIA с мутацией EGFR exon19del — сопоставление NCCN vs ESMO.

✓ Сильные стороны

  • Прямое сопоставление двух гайдлайнов «бок о бок» с явным разделом «Анализ расхождений»
  • Ответ на языке запроса (русский) — лучше, чем Navigator
  • Указание конкретной версии источника (NCCN v6.2026)
  • Высокий лимит ввода (300 слов) удобен для сложных случаев
  • Возможность загрузки собственных локальных протоколов

⚠ Слабые стороны

  • Sources — только названия документов, без прямых гиперссылок
  • База знаний заметно уже, чем заявлено в FAQ и Mórbius
  • Не протестирован режим Deep Search
  • Нет явного дисклеймера о дате актуальности индекса

Итог: Точный, хорошо специализированный инструмент для быстрого сравнения международных клинических рекомендаций — редкая и ценная функция, которую сложно быстро получить вручную.

URL: mdcopilot.online/mdspeaker · Категория: FOR ALL · Статус: Стабильный

AI-инструмент медицинской диктовки, создающий структурированную клиническую документацию из голосовой записи. Типы записи: Simple medical record, Consultation with AI, Dialogue doctor-patient, Chemotherapist's appointment, Oncologist's appointment, Meeting protocol. Три модели распознавания: MedPro (accurate), MedLite (lite), MedBro (reliable). Тарификация: 1 кредит за минуту.

Ограничение тестирования

Сервис принципиально требует живого аудиоввода через микрофон — интерфейс не предоставляет способа загрузить готовый аудиофайл. Поскольку тестирование проводилось через браузерную автоматизацию без реального аудиоввода, полноценно протестировать качество распознавания и AI-структуризации не удалось. Заявить о фактическом качестве расшифровки было бы недобросовестно без реальной записи голоса.

✓ Сильные стороны (по UI/описанию)

  • Специализация под медицинские сценарии (химиотерапевт, онколог)
  • Явный шаг с согласием пациента на запись — важная комплаенс-деталь
  • Выбор из 3 моделей распознавания (accurate/lite/reliable)
  • Функция объединения записей (Merge recordings)
  • Тарификация по минутам — интуитивно понятна

⚠ Риски (не проверено)

  • Неизвестно качество распознавания русской медицинской речи
  • Неизвестна диаризация (разделение реплик по говорящим)
  • Неясно поведение при обрыве связи — есть ли автосохранение
  • Нет возможности загрузить существующий аудиофайл

Итог: Не оценено. Рекомендуется отдельный ручной тест с реальной аудиозаписью на русском языке (2–3 минуты) для оценки точности распознавания и структурирования.

URL: mdcopilot.online/trialscout · Категория: FOR ALL · Статус: Стабильный

AI-ассистент для поиска и подбора клинических исследований с активным набором пациентов. Форма: поле диагноза, выбор страны, чекбоксы фазы (1–4), поле клинических деталей (до 100 слов). Тарификация: 1 кредит за запрос.

Тестовый сценарий: relapsed refractory multiple myeloma (triple-class refractory), фазы 2 и 3, клинические детали (58 лет, ECOG 1, del17p, поиск биспецифических антител/CAR-T).

✓ Сильные стороны

  • Анализ выходит за рамки списка: сопоставление критериев включения/исключения с профилем пациента
  • Явное указание на потенциальный конфликт (рефрактерность к даратумумабу vs требование протокола ELISA)
  • Исследования соответствуют реальным программам разработки 2025–2026 гг. (AZD0120/DURGA, REGN7945, элранатамаб)
  • Наличие номера NCT для верификации
  • Неудачный запрос не списал кредит

⚠ Слабые стороны

  • Поле диагноза чувствительно к языку ввода — русский дал «no results», английский сработал
  • Потенциальный сбой в отображении списания кредитов
  • Нет указания региональной доступности исследований

Итог: Один из самых практически ценных инструментов — демонстрирует реальное сопоставление критериев включения/исключения с клиническим профилем пациента. Требует исправления языковой чувствительности.

URL: mdcopilot.online/mdscan · Категория: FOR ALL · Статус: BETA

AI-инструмент для анализа медицинских изображений. Поддерживаемые типы: CT, MRI, X-ray, мазок костного мозга, мазок периферической крови, фото кожи, УЗИ, ЭКГ, фото медицинского документа. Загрузка: JPG/PNG/GIF/WEBP до 5 МБ. Явный дисклеймер: «This is an experimental model and is not intended for clinical use!»

Тестовый запрос: синтетическое изображение ЭКГ (Lead II) с подъёмом сегмента ST и высокоамплитудным Т-зубцом (STEMI-паттерн), мужчина 54 года, острая загрудинная боль 40 минут.

✓ Сильные стороны

  • Не шаблонный ответ: количественные параметры (ЧСС, интервалы) рассчитаны по факту изображения и совпали с заложенными значениями
  • Корректная медицинская интерпретация STEMI-паттерна
  • Явный дисклеймер об экспериментальном статусе — ответственный подход
  • Прозрачная тарификация (3 кредита) и корректное списание

⚠ Слабые стороны

  • Ответ не предложил неотложной тактики (активация кат. лаборатории, антиагреганты)
  • Ответ полностью на английском при русскоязычном контексте
  • Тест ограничен синтетическим изображением, один тип данных (ЭКГ)
  • Качество на ЭКГ не гарантирует аналогичное качество на КТ/МРТ/гистологии

Итог: Впечатляющий результат для BETA-функции: система продемонстрировала реальное количественное считывание параметров из изображения, а не шаблонный ответ. Оценка ограничена объёмом тестирования (один тип данных, синтетическое изображение).

URL: mdcopilot.online/hlai · Категория: SPECIAL APPS · Статус: demo

«Intelligent HLA-matching donor search» — инструмент подбора HLA-совместимого донора гемопоэтических стволовых клеток по фенотипу пациента. Форма: 20 полей для ввода аллелей по локусам A, B, C, DRB1, DQB1. Результаты в трёх вкладках: Matched, 1 Mismatch, AI Recommendations.

Тестовый сценарий: предзаполненный демонстрационный фенотип → SEARCH → кросс-валидация 5 упомянутых AI доноров с данными вкладок Matched и 1 Mismatch.

✓ Сильные стороны

  • Точная, проверяемая грунтованность рекомендаций — не выявлено ни одного случая выдумывания донора или показателя
  • Клинически грамотное обоснование выбора (возраст, пол, приоритет DRB1 vs DQB1)
  • Ответственная маркировка demo-статуса
  • Единая архитектура из трёх вкладок (Matched / Mismatch / AI) — хорошее разделение ответственности
  • AI Recommendations предложили проверить HLA-DPB1, CMV-серостатус, ABO — соответствует реальной практике

⚠ Слабые стороны

  • Непрозрачная логика ранжирования между вкладками Matched и 1 Mismatch
  • Пометка HINT «FURTHER EXAMINATION» без сопроводительного комментария — неясен критерий
  • Ответ на английском при русскоязычном клиническом описании
  • Тестирование ограничено демонстрационным набором данных

Итог: Несмотря на статус demo, функция AI Recommendations продемонстрировала точную, проверяемую и клинически обоснованную работу поверх реальных результатов поиска, без признаков галлюцинаций.

Сквозные находки

✓ Системные сильные стороны

  • RAG-архитектура с прозрачностью: пользователь видит, какие источники запрашивались — повышает доверие
  • Клиническая точность: ответы содержат конкретные HR, ДИ, % событий, номера РКИ, версии гайдлайнов
  • Честная маркировка зрелости: demo/alpha/BETA статусы — платформа не выдаёт экспериментальное за готовое
  • Узкая специализация: глубина в онкогематологии вместо попытки охватить всю медицину
  • Низкая стоимость запросов: 1 кредит для большинства операций

⚠ Системные риски

  • Языковая согласованность: часть разделов (Navigator, MD-Scan, HLAI) отвечает на английском при русскоязычном запросе — системная проблема
  • Отсутствие уточнений: система не запрашивает недостающие клинические данные, формируя ответ на основе предположений
  • Дисклеймеры: нет явного дисклеймера о том, что ответ не является медицинским назначением (кроме общей плашки)
  • Биллинг: задержки/сбои в отображении списания кредитов (Mórbius, TrialScout)
